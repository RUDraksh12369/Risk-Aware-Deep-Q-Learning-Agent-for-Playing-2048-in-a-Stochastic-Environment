2048 Risk-Aware RL: additional inference options

Run commands from the repository root after installing requirements and
activating the virtual environment. The README.md is the canonical guide for
installation, training, evaluation, checkpoints, and GUI modes.

Train one model

Use the matching command below to train an individual variant. The default
checkpoint path is shown in each command. If that checkpoint already exists,
training resumes it; use --fresh-run only when you intentionally want a new
experiment. --episodes is the total target episode count.

DQN
python -m training.train --episodes 2000 --seed 42

Double DQN
python -m training.train_doubledqn --episodes 2000 --seed 42

Dueling DQN
python -m training.train_duelingdqn --episodes 2000 --seed 42

Dueling Double DQN
python -m training.train_double_dueling_dqn --episodes 2000 --seed 42

Risk-Aware Dueling Double DQN (RA-D3QN)
python -m training.train_risk_aware --episodes 2000 --seed 42 --risk-coefficient 0.1

Evaluate a trained model

Use the checkpoint for the model you trained. These commands run 100 seeded
greedy evaluation episodes:

python -m training.evaluate --checkpoint models/dqn_baseline_2048.pt --episodes 100
python -m training.evaluate --checkpoint models/doubledqn_2048.pt --episodes 100
python -m training.evaluate --checkpoint models/dueling_dqn_shared.pt --episodes 100
python -m training.evaluate --checkpoint models/dueling_double_dqn_2048.pt --episodes 100
python -m training.evaluate --checkpoint models/ra_d3qn_2048.pt --episodes 100

Demo the trained models in the GUI

Run the matching block to open a playable demo controlled by that trained
checkpoint. The GUI labels the selected model. The first four variants use
their ordinary legal-action greedy policies; the RA-D3QN block below uses the
checkpoint's saved risk settings. Quit a demo with Q or Esc. Each checkpoint
must already exist. To show all five models, run each block in sequence.

DQN
$env:DQN_CHECKPOINT = "models\dqn_baseline_2048.pt"
Remove-Item Env:DQN_INFERENCE_POLICY -ErrorAction SilentlyContinue
python -m gui.pygame_demo --mode agent --agent inference.autoplay:choose_action

Double DQN
$env:DQN_CHECKPOINT = "models\doubledqn_2048.pt"
Remove-Item Env:DQN_INFERENCE_POLICY -ErrorAction SilentlyContinue
python -m gui.pygame_demo --mode agent --agent inference.autoplay:choose_action

Dueling DQN
$env:DQN_CHECKPOINT = "models\dueling_dqn_shared.pt"
Remove-Item Env:DQN_INFERENCE_POLICY -ErrorAction SilentlyContinue
python -m gui.pygame_demo --mode agent --agent inference.autoplay:choose_action

Dueling Double DQN
$env:DQN_CHECKPOINT = "models\dueling_double_dqn_2048.pt"
Remove-Item Env:DQN_INFERENCE_POLICY -ErrorAction SilentlyContinue
python -m gui.pygame_demo --mode agent --agent inference.autoplay:choose_action

RA-D3QN, using its saved risk settings
$env:DQN_CHECKPOINT = "models\ra_d3qn_2048.pt"
$env:DQN_INFERENCE_POLICY = "original"
python -m gui.pygame_demo --mode agent --agent inference.autoplay:choose_action

Optimized RA-D3QN GUI policy (PowerShell)

This selects the included RA-D3QN checkpoint and uses an inference-time risk
coefficient and heuristic tie-breaker. These settings do not modify the
checkpoint. The heuristic only chooses between legal actions whose Q-values
fall within the configured relative tolerance.

$env:DQN_CHECKPOINT = "models\ra_d3qn_2048.pt"
Remove-Item Env:DQN_INFERENCE_POLICY -ErrorAction SilentlyContinue
$env:DQN_RISK_COEFFICIENT = "0.20"
$env:DQN_TIE_TOLERANCE = "0.01"
$env:DQN_HEURISTIC_MONOTONICITY = "1.0"
$env:DQN_HEURISTIC_SMOOTHNESS = "1.0"
$env:DQN_HEURISTIC_EMPTY_CELLS = "1.0"
$env:DQN_HEURISTIC_CORNER = "1.0"
python -m gui.pygame_demo --mode agent --agent inference.autoplay:choose_action --delay-ms 140

The GUI logs the loaded checkpoint and policy settings at startup. To use the
checkpoint's saved risk coefficient and original greedy policy instead, select
the original policy and clear inference-only overrides:

$env:DQN_CHECKPOINT = "models\ra_d3qn_2048.pt"
$env:DQN_INFERENCE_POLICY = "original"
Remove-Item Env:DQN_RISK_COEFFICIENT -ErrorAction SilentlyContinue
Remove-Item Env:DQN_TIE_TOLERANCE -ErrorAction SilentlyContinue
Remove-Item Env:DQN_HEURISTIC_MONOTONICITY -ErrorAction SilentlyContinue
Remove-Item Env:DQN_HEURISTIC_SMOOTHNESS -ErrorAction SilentlyContinue
Remove-Item Env:DQN_HEURISTIC_EMPTY_CELLS -ErrorAction SilentlyContinue
Remove-Item Env:DQN_HEURISTIC_CORNER -ErrorAction SilentlyContinue
python -m gui.pygame_demo --mode agent --agent inference.autoplay:choose_action --delay-ms 140

Alternatively, the original callable can be selected directly with
--agent inference.autoplay:choose_action_original.
